Crud Rules & GitHub Pages Hosting

Verified Serve & Turn Rules

  • 3-Strike Serve Rule: Missing a serve adds a strike (1/3, 2/3). On the 3rd miss, the server loses 1 life and keeps serving until they make a legal hit or are eliminated.
  • Next Player Serves After Life Loss: Whenever any player loses a life (Dead Ball, Potted On You, or Foul), the ball resets to SERVE PHASE and the next alive player after the penalized player becomes the new server.

How to Publish on GitHub Pages

  1. Create a new public repository on GitHub (e.g., crud-referee).
  2. Upload this single HTML file and rename it to index.html.
  3. Go to Settings → Pages, select the main branch, and click Save.
  4. GitHub Pages serves over HTTPS automatically, which enables Chrome/Safari Microphone & Speech Recognition on mobile phones!
